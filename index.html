HTML5

HTML Foundations

What is HTML?

HTML stands for HyperText Markup Language. It gives a webpage its structure and content.

Basic document 
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
PartMeaning
<!DOCTYPE html>Declares HTML5.
<html>Root element.
<head>Page metadata.
<title>Browser-tab title.
<body>Visible page content.
Execute it: create practice.html in VS Code, type the structure, save with ⌘S, open it in a browser, change the heading, save, then refresh.

<a> creates a hyperlink and href specifies its destination. <ul> is an unordered list, <ol> an ordered list, and <li> a list item.

4. Tables — Understand the Nesting

<table border="1">
  <thead>
    <tr>
      <th>Day</th>
      <th>Time</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Monday</td>
      <td>7:00 PM</td>
    </tr>
  </tbody>
</table>
Read from outside to inside: table → table section → row → cell. <th> is a header cell; <td> is a data cell.

5. Images & File Paths

<img src="cat.jpg" alt="A cat" width="300">

If cat.jpg is in the same folder as the HTML file, the simple relative path above works. If the filename or path is wrong, the browser cannot load the image. alt provides a text alternative.

6. Video

<video width="400" controls>
  <source src="aral loop.mp4" type="video/mp4">
  Your browser does not support the video tag.
</video>

The controls Boolean attribute displays browser playback controls. The nested <source> identifies a media resource and its MIME type.

7. Forms — The Big Picture

A form contains controls that collect user input. Our Activity 2 focused on HTML controls and browser validation; it did not include a server endpoint that stores the submitted data.

<form>
  <label for="fullname">Full Name:</label>
  <input type="text" id="fullname" name="fullname" required>
</form>

8. Important Form Attributes

AttributeWhat to remember
typeDetermines the kind of input control.
idUniquely identifies an element; a label's for value can target it.
forOn a label, should match the associated control's id.
nameNames the form field in submitted form data.
valueDefines the value associated with a control/option.
placeholderShows hint/example text inside certain controls.
requiredParticipates in browser validation and makes the control mandatory.
min / maxSet lower/upper constraints for applicable controls such as number.
multipleAllows multiple choices in an applicable select control.

9. Radio vs Checkbox

<input type="radio" id="first" name="year" value="1st">
<label for="first">1st Year</label>

<input type="checkbox" id="htmlSkill" name="skills" value="HTML">
<label for="htmlSkill">HTML</label>

Radio buttons that share a name form a single-choice group. Checkboxes are independent controls, so several may be selected.

10. Select, Option & Multiple

</select>

<select id="hobbies" name="hobbies" multiple>

11. Textarea, File, Submit & Reset

<textarea id="reason" name="reason" rows="4" cols="40"></textarea>
<input type="file" id="studentfile" name="studentfile">
<input type="submit" value="Submit">
<input type="reset" value="Reset">

12. Common Errors to Spot

Wrong: <thread> when you mean <thead>.
Label mismatch: for="email" will not explicitly connect to a control whose id is studentemail.
Duplicate IDs: IDs should be unique within one HTML document.
Wrong media path: a typo in src prevents the resource from loading.

CSS

CSS Foundations

What is CSS?

CSS (Cascading Style Sheets) controls presentation such as color, spacing, fonts, borders, and layout.

p {
  color: blue;
  font-size: 18px;
}

Selector: p • Property: color • Value: blue.

MethodExample
Inline<p style="color:red;">
Internal<style> rules inside the HTML document
External<link rel="stylesheet" href="style.css">

Responsive Design

Responsive Web Design

Responsive design adapts a page to different screen sizes.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

@media (max-width: 600px) {
  .container {
    width: 100%;
  }
}

JavaScript

JavaScript Essentials

JavaScript adds behavior and interactivity to webpages.

<button id="helloBtn">Click Me</button>

<script>
const button = document.getElementById("helloBtn");

button.addEventListener("click", function () {
    alert("Hello!");
});
</script>
Think of the roles: HTML = structure, CSS = presentation, JavaScript = behavior.

JSON

JSON Essentials

JSON is a text format commonly used to represent and exchange structured data.

{
  "name": "Juan",
  "course": "BSIT",
  "skills": ["HTML", "CSS"]
}
JSON uses key/value pairs. In valid JSON, property names and string values use double quotes.

AJAX

AJAX Concept

AJAX describes techniques for requesting data from a server and updating a webpage without requiring a traditional full-page reload.

fetch("data.json")
  .then(response => response.json())
  .then(data => console.log(data));

Encryption transforms data using a key so authorized parties can recover it. Hashing produces a fixed-size digest and is generally designed as a one-way operation.

PHP & MySQL

PHP & MySQL Overview

PHP is commonly used for server-side web programming. MySQL is a relational database management system. They can be used together so a server-side PHP program reads or changes database data.

<?php
$name = "Juan";
echo "Hello " . $name;
?>

PHP

Sessions Overview

A PHP session can preserve server-side data associated with a user's browsing session across requests.

<?php
session_start();
$_SESSION["username"] = "Juan";
?>
