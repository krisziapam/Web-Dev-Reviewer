The HTML Activity 1 and Activity 2 sections reflect the activities completed with ChatGPT.
The other topic pages are foundational review material because the actual lecture PDFs were not supplied.

## Publish
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Settings → Pages → Deploy from a branch.
4. Choose `main` and `/ (root)`.
5. Save.

For exact instructor-aligned coverage, add/upload the lecture PDFs and regenerate the reviewer from those sources.
